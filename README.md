# Discord Meme Bot

A simple Discord bot built using Python and discord.py.

I made this project to learn how Discord bots work, how to use APIs, and how to handle user commands. The bot can send memes, random facts, animal pictures, and a few other fun commands.

## Features

- `/meme` - Get a random meme
- `$meme` - Get a random meme
- `$dog` - Random dog image
- `$cat` - Random cat image
- `$fact` - Random fact
- `$coinflip` - Flip a coin
- `$ping` - Check if the bot is online
- `$help` - Show available commands

## Built With

- Python
- discord.py
- requests
- Discord Application Commands (Slash Commands)

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/Discord-Meme-Bot.git
```

Install the required packages:

```bash
pip install discord.py requests
```

Add your Discord bot token and run:

```bash
python bot.py
```

## Why I Built This

I wanted to get some hands-on experience with Python projects and APIs while building something fun that could actually be used in a Discord server.
